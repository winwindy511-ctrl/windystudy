## 一、简介

本书是一本面向中文 NLP 的"原理 + 实战"入门到进阶图书，全书共 19 章、407 页。技术栈覆盖两条主线：一是传统统计与规则方法（规则分词、统计分词、HMM、条件随机场、TF-IDF、文本相似度、新词发现等），二是深度学习方法（Word2Vec 词向量、BERT、循环/卷积神经网络、分布式深度学习等），并延伸到工程系统（搜索引擎 Solr Cloud 与 Elasticsearch、文本聚类、关键词提取与文本摘要、语言模型）。书中同时使用 Java 和 Python 两门语言编排大量代码实例，这是它区别于多数纯 Python NLP 书的显著特点。配套完整实战项目：对话机器人实战、搜索引擎项目实战、推荐算法系统实战。面向读者为 NLP 初学者、在职工程师与转行者，官方宣传语强调"契合公司实际工作场景技能，侧重实战"。出版背景上，本书出版于 2023 年，主体内容是前大模型时代的经典 NLP 技术栈（Word2Vec、Seq2Seq、BERT 一代），从目录看未设大语言模型/Prompt/Agent 专章，大模型相关内容主要体现在作者的后续专栏与系列讲座中。本书属清华大学出版社"人工智能科学与技术丛书"，与陈敬雷《分布式机器学习实战》为同丛书姊妹篇。

## 四、核心概念

（每条一句话定义；多数为本书目录明确涉及的概念，个别标注者为其配套连载中出现、书内涉及程度未核实）

1. **自然语言处理（NLP）**：让计算机理解、处理和生成人类语言的技术领域，涵盖分词、句法、语义到对话、翻译等多个层次。
2. **中文分词**：把连续的中文句子切分成有意义的词语，是中文 NLP 的第一道基础工序。
3. **规则分词（最大匹配法）**：按词典从前往后（正向）或从后往前（逆向）取最长匹配切词，双向最大匹配则两者结合取更优结果。
4. **统计分词 / HMM**：把分词看作字标注（B/M/E/S 四状态）问题，用隐马尔可夫模型的转移与发射概率求解最优切分序列。
5. **词性标注（POS Tagging）**：为句中每个词标上名词、动词等词性标签，是句法和语义分析的前置任务。
6. **命名实体识别（NER）**：从文本中识别出人名、地名、机构名等实体并分类，信息抽取的核心任务之一。
7. **依存句法分析**：分析词与词之间的支配关系（主谓、动宾等），把句子表示成依存结构树。
8. **语义角色标注（SRL）**：以谓词为中心标注施事、受事等论元角色，获得浅层语义结构。
9. **TF-IDF**：用"词频×逆文档频率"衡量一个词对文档的重要程度，是经典的文本特征加权方法。
10. **词袋模型（BoW）**：忽略词语顺序、只统计词频的文本向量化方式，是最朴素的文本表示。
11. **文本/语义相似度**：度量两段文本在字面（如编辑距离、Jaccard）或语义空间（向量夹角余弦）上的接近程度，用于匹配、去重、推荐。
12. **条件随机场（CRF）**：一种判别式概率图模型，能融入上下文特征，长期是序列标注（分词、NER）的主力算法。
13. **新词发现与短语提取**：基于词频、凝固度等统计指标从语料中自动挖掘未登录新词和常用短语。
14. **倒排索引**：从"词→文档列表"的映射结构，是 Solr、Elasticsearch 等搜索引擎实现毫秒级检索的核心数据结构。
15. **Solr Cloud / Elasticsearch**：基于 Lucene 的分布式搜索引擎，支持集群、分片与近实时检索，常用于站内搜索和日志分析。
16. **Word2Vec 词向量**：把词映射为稠密向量的模型，含 Skip-Gram 与 CBOW 两种结构，训练技巧有负采样和层序 Softmax，能表达词间相似与类比关系。
17. **TextRank / PageRank**：源自网页排名的图排序算法；TextRank 把句子或词当节点、相似度当边，迭代选出关键词和关键句。
18. **文本分类**：把文档归入预定义类别（如垃圾邮件识别），从朴素贝叶斯、SVM 发展到 TextCNN、BERT 等深度模型。
19. **文本聚类**：无监督地把相似文档聚成一簇（如 K-Means），无需标注数据。
20. **文本摘要**：自动生成文本要点，分抽取式（从原文挑句）与生成式（重新组织语言）、单文档与多文档。
21. **语言模型（Language Model）**：计算一个词序列出现概率的模型，从 n-gram 统计模型演进到神经网络语言模型，是预训练模型的源头。
22. **BERT**：基于 Transformer 双向编码的预训练语言模型，通过"预训练+微调"范式刷新了大量 NLP 任务成绩。
23. **Seq2Seq 与注意力机制**：编码器-解码器框架处理变长序列转换（翻译、摘要），注意力机制让解码时动态聚焦源序列的相关部分。
24. **LSTM/GRU**：通过门控机制缓解 RNN 梯度消失的循环神经网络结构，是 BERT 之前序列建模的主流。
25. **评价指标（准确率/精确率/召回率/F1/AUC）**：衡量分类与标注模型好坏的常用量化指标，模型上线前评估的必备工具。

（另注：作者 2024 年后的"大模型企业应用落地系列"讲座涉及大语言模型、Prompt、RAG、AI Agent、多模态等概念，从公开资料看不属于本书 19 章目录的明确组成部分。）

## 补充（问答中收集）

- 问题：如何自己训练一个模型出来（2026-10-25，websearch ×1）
  - 微调是个人入门的主路径：选一个预训练模型 + 数据集 → 用微调框架（如 LLaMA-Factory）→ 训练 → 评估；LoRA/QLoRA 是"轻量级微调"：不动原模型全部参数，只新增一层低秩矩阵（W₀+ΔW，ΔW 就是要额外训练的那部分），可训练参数量从几十亿降到几千万，消费级显卡即可跑（知乎《LoRA：大模型轻量级微调》、阿里云 PAI 的 Llama3-8B 微调案例）。
  - 从零预训练也有公开教程：Karpathy 的 nanoGPT（教学级最小实现）、SwanLab《从零预训练一个自己的大模型》（用 wiki 数据集）、datawhalechina/happy-llm（系统化 LLM 学习教程）；从零训练通常需要多卡（DeepSpeed 并行）与几十 GB 以上语料。
  - 数据是关键变量：如 Llama3-8B 的预训练数据约 15 万亿 tokens（阿里云 PAI 文档引述），高质量、去重、多样性比单纯加大数据量更重要。
