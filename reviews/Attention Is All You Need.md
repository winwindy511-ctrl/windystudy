# Attention Is All You Need · 学习笔记

2026-10-23

先说明一句：这其实不是一本书，是 Vaswani 等八位谷歌研究者 2017 年的十五页会议论文。它没有铺陈理论，而是干了一件事——把序列建模里"必须一步步算"这个前提删掉。

## 一句话抓住它

在做翻译这类「把一条序列变成另一条序列」的任务时，过去必须按词序逐步计算（RNN）；这篇论文说，只靠注意力就能让任意两个词直接互相看见，训练可以整段并行，效果还更好。

## 知识骨架：七个模块，一条递进线

**问题（循环为什么必须换掉）→ 内核（注意力是一次带权检索）→ 升级（一个头不够用）→ 组装（把零件搭成编码器和解码器）→ 补丁（把顺序塞回去）→ 辩护（凭什么能替代循环和卷积）→ 证据（翻译成绩与消融）**

这条线不是并列的七个知识点，而是"先提出一个瓶颈，再给出机制，机制还缺什么就补什么，最后回到证据"的一条因果链。

### 问题：串行计算掐住了规模

**序列转导**（把一条序列映射成另一条序列，翻译是最典型的例子）当年主流做法是**编码器-解码器**（先用一个网络把整句压成表示，再用另一个网络把它逐词吐出来）加循环网络。循环网络的第 t 步必须等第 t−1 步算完，一条一百个词的句子就得串行算一百步；GPU 再多也只能干等，句子越长越慢，前面的信息还容易被冲淡。另一条路是用卷积替换循环，能并行，但两个相距很远的词要靠层层卷积"传话"，传话的层数随距离增长。论文要的东西很明确：既要整段并行，又要任意两个位置一步直达。

### 内核：注意力就是一次带权检索

论文把注意力写成一次检索：每个位置同时扮演三种角色——**查询、键、值**（Query / Key / Value：我想找什么、我身上挂什么标签、我实际携带什么信息）。用查询和所有键做点积算出相似度，除以一个缩放因子防止数值过大，再用 softmax 归一成权重，最后按权重把值加起来。这就是**缩放点积注意力**。缩放那一步不是装饰：维度一高，点积的方差就大，softmax 会被推到极端，梯度几乎消失。相比当时常用的加性注意力（用一个小网络算相似度），点积能写成矩阵乘法，在 GPU 上快得多、也省内存——这是它能取代循环的工程前提，不是数学上的优雅。

### 升级：一个头会看漏，所以要多个头

一次注意力只产出一套权重，等于把"这个词该跟谁近"压缩成单一答案，多种关系（邻近、句法、指代）互相平均掉。**多头注意力**把查询、键、值各用一组学出来的矩阵投影到八个低维子空间，各自算一遍注意力，再拼接、再投影。于是不同的头可以分工，论文附录的可视化显示确实有头在追踪句法结构。它在模型里有三种用法：编码器内部全句互看；解码器内部只能看已生成的部分；解码器向编码器发查询、读取编码器输出的键和值。解码器那种"不许看未来"靠**掩码**实现——把未来位置的分数设成负无穷，softmax 之后权重就是零。

### 组装：六层同样的积木，靠两条胶水粘住

编码器和解码器各由六层相同结构叠起来。编码器每层两块：**自注意力**（查询、键、值都取自同一句话，所以每个词能直接看全句），再叠一个逐位置的**前馈网络**（对每个位置独立施加同一组两层全连接，相当于给每个位置一次单独加工的机会）。解码器多一块交叉注意力。每块外面套**残差连接**（把输入原样加回输出，给梯度留一条高速公路），后面接**层归一化**（把每个位置的数值拉回稳定范围）。没有这两样，六层堆起来就很难训。所有子层统一到 512 维，输入输出词嵌入和最后那个 softmax 前的矩阵共享参数。

### 补丁：注意力天生不认顺序

注意力本质上是集合运算：把词序打乱，输出只是跟着换位置，模型分不出"狗咬人"和"人咬狗"。所以必须在入口补上顺序信息。论文用不同频率的正弦和余弦函数生成**位置编码**，直接加到词向量上。选固定函数而不是可学习向量，理由有两条：对固定的偏移量，后面的位置编码可以写成前面位置编码的线性变换，模型容易学"相对位置"；训练时没见过的更长句子也能算出来。实验里两种做法效果几乎一样，选固定的是为了外推这个可能性。

### 辩护：三条判据，一次正面交锋

论文没有停在"跑得快"，而是拿三个指标和循环、卷积逐项比：每层要多少计算量、最少要串行几步、任意两个位置之间的最长**路径长度**。自注意力每层是长度的平方级计算，但串行步数是一步、路径长度也是一步；循环要串行 n 步、路径长 n；卷积的路径随层数对数增长。这三条解释了"为什么效果好"，也顺带承认了代价：长度平方意味着句子一长就贵，论文只把"只看邻域的受限注意力"写进未来工作，并没有实现。

### 证据：不是只赢在速度

训练用 WMT 2014 英德约 450 万句对、英法约 3600 万句。基础模型八块 P100 训十二小时，大模型训三天半。英德拿到 28.4 **BLEU**（机器翻译的自动评分，看输出与参考译文的词块重合度），比当时最好结果还高两个点以上；英法单模型 41.8。**消融实验**（把某个零件拆掉或换掉，看分数掉多少）逐项检查了头数、维度、dropout、位置编码方式和模型规模，证明每个零件都在干活。最后把同一套结构搬到英语成分句法分析上，F1 到 91.3（半监督 92.7），用来说明它不是只为翻译定制的。

## 记忆挂钩：把零件串成因果和立场

### 它在跟谁吵架

主对手是循环网络路线（Sutskever 的 seq2seq、谷歌自家的 GNMT）：对方的隐含前提是"要建模顺序，就必须按顺序算"。次对手是卷积路线（ConvS2S、ByteNet）：它们已经拿到并行，但接受了"远距离要多跳几层"这个折中，本文主张一步直达。还有一场更隐蔽的争论：注意力此前普遍被当成循环网络的配件（Bahdanau 那篇就是给 RNN 加的注意力），本文反过来主张注意力才是主干，循环才是可以拆掉的零件。对照着看，问题模块负责点火，内核和多头给出替代方案，辩护模块正面回答"凭什么"。

### 前因后果

2014 年注意力被引入机器翻译，解决了长句对齐；2015 到 2016 年卷积路线把并行做出来了，却把代价转移到路径长度上。同时谷歌内部已经有多 GPU 训练和 tensor2tensor 工程能力——算力第一次不再是主要瓶颈，唯一卡住规模的就是那个串行结构。所以真正的问题不是"注意力好不好用"，而是"能不能把唯一的串行瓶颈拆掉"。这也解释了论文为什么把复杂度表放在那么重的位置，以及为什么三天半就能刷到最好成绩：红利来自并行，不是来自参数更多。

### 核心概念怎么连起来

串行依赖 → 训练慢、长句遗忘 → 改用注意力做位置间通信 → 注意力对顺序无感 → 必须补位置编码 → 单头把多种关系平均掉 → 多头分工 → 想堆深就会数值不稳 → 残差加层归一化 → 解码时不能偷看答案 → 掩码 → 每层成本随长度平方增长 → 长序列吃亏 → 才有后来的局部与稀疏注意力。

顺着这条链，零件不是背下来的，是被问题一个个逼出来的。反过来推也成立：如果去掉位置编码，模型立刻变成词袋；去掉掩码，训练时就能偷看答案，推理必然崩；去掉残差和归一化，六层堆不起来。这也是判断"哪个零件最关键"的方法——看拆掉之后哪条因果断掉。

### 和别人的对话

- Bahdanau 等 2014 的注意力机器翻译：本文的直系祖先，也是要超越的对象，用的是加性注意力加循环。
- Sutskever 等 2014 的 seq2seq：确立编码器-解码器骨架，本文沿用骨架、换掉内部零件。
- ConvS2S 与 ByteNet：同样想摆脱串行，选择卷积，本文选择注意力。
- BERT：只留编码器、改成双向、加上预训练，把 Transformer 从翻译模型变成通用语言表示。
- GPT 系列：只留解码器、坚持自回归、猛堆规模，走成另一条主线。
- Longformer、BigBird 一类工作：正面处理本文轻描淡写的平方复杂度。
- 《The Annotated Transformer》：逐行复现的教学版本，适合核对实现细节。

## 如果考试遇到这本书相关的题，这几个点必须踩到

1. 它解决的是**并行化**问题，不是"注意力比循环更聪明"。核心矛盾是循环的串行依赖让算力用不上。
2. 注意力的形式是查询、键、值加权求和，缩放因子除以键维度的平方根，作用是防止 softmax 饱和。
3. 多头不是简单重复，是把表示投影到多个子空间，让不同头捕捉不同类型的关系。
4. 位置编码不可省：注意力是集合运算，不补顺序信息就分不出语序。
5. 残差连接与层归一化是"能堆深"的前提，不是可选项。
6. 三条对比判据：每层复杂度、最少串行步数、最大路径长度；代价是长度的平方。
7. 证据边界要清楚：两个翻译任务加一个句法分析，没有预训练、没有 decoder-only、没有长序列方案。
8. 标题是修辞不是结论：前馈网络、残差、归一化、位置编码都不是注意力。
9. 历史意义在于把"按时间步计算"换成"按矩阵乘计算"，规模定律才有发挥空间。

## 论述题答题骨架

问"你怎么看这篇论文"，可以按这个顺序组织：

先定位——它没有发明注意力，而是证明注意力可以独立当主干，删掉了一个此前没人质疑的前提。再拆论证——问题（串行瓶颈）→ 机制（缩放点积与多头）→ 理由（三项复杂度指标）→ 证据（翻译 SOTA、消融、句法迁移）。然后划边界——任务面窄、成本论证粗、平方复杂度被搁置、标题绝对化。最后看影响——BERT 与 GPT 两条支线都从它分叉，真正的遗产是把序列建模变成可并行的矩阵运算。收口可以落在方法论的判断上：这是一次"删除假设"式的成功，价值在于重画了可能性边界，而不是增加了一个模块。
