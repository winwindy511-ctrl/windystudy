# 《国富论》 · 学习笔记

日期：2026-10-22

## 一句话概括

《国富论》要回答的问题是「一个国家的财富到底靠什么长出来」。斯密的答案是：靠**分工**（把一件活拆成很多小工序，各人专做一道，做得又快又精）提高生产效率，靠自由竞争让每个人在追逐私利时无意中增进社会利益，而政府只要守好国防、司法、公共工程这三件事就够了——这也意味着要抛弃当时流行的「重商主义」那套把金银当财富、用政策干预贸易的做法。

## 第一层：知识骨架

全书可以分成五块，讲的是一个逐步推进的故事：

1. **生产怎么变快（分工与价值）**：先讲国民财富增长的引擎——分工，以及交换、货币、价格这些市场的基本零件。
2. **增长靠什么垫底（资本）**：光有分工还不够，还得有资本垫底。这部分讲资本怎么积累、怎么分类、怎么使用才有效率。
3. **富国是怎么长出来的（历史回顾）**：用欧洲（尤其是罗马帝国崩溃后的欧洲）的真实历史，检验前面讲的增长逻辑——为什么有的地方富起来，有的地方被制度锁死。
4. **错的政策为什么错（批判重商主义与重农主义）**：把当时两套主流经济政策拉出来批判，正面推出自由贸易与自由竞争。
5. **政府该干什么、钱从哪来（财政）**：给出政府的合理边界（国防、司法、公共工程），以及税收与公债的原则。

这五块的递进关系是：先讲清楚「财富靠分工与资本增长」（理论），再用历史验证（实证），再批判错误政策、提出正确制度（政策），最后回答政府该干什么（边界）——从抽象到具体，从理论到制度。

## 第二层：骨架上的主要内容

**生产怎么变快**

这部分的核心是**分工**。斯密用制针工场的例子：一个人从头到尾做一根针，一天做不出几根；但把工序拆开，让每个工人专做一道，十个人一天能做出四万八千根。分工为什么厉害？因为熟能生巧、省去转换工序的时间、还能逼出专用机器。分工不是人设计出来的，而是人天生有**交换的倾向**（想拿自己多余的东西换别人多余的东西），我专门打铁、你专门种粮、然后交换，对大家都好。但分工能细到什么程度，取决于**市场范围**（能交换的人口规模和购买力）：市场越大、能交换的人越多，分工才越细——小镇上只能有一个什么都看的医生，大城市才有专科医生。

接着讲交换的媒介——**货币**：以物易物太麻烦，人就想出用贵金属当一般等价物，货币就这么来了。然后是价格理论：商品的价格由三部分构成——劳动拿的**工资**、资本拿的**利润**、土地拿的**地租**，合称**三种收入**。斯密区分了**自然价格**和**市场价格**：自然价格是工资、利润、地租的「自然率」加起来得出的、商品长期该卖到的价，是价格的引力中心；市场价格是现实成交价，围绕自然价格上下波动，供不应求就涨、供过于求就跌。他还提出**劳动价值论**（劳动是衡量商品价值的普遍尺度）：一件东西值多少，最终要看它支配了多少别人的劳动。

**增长靠什么垫底**

分工要运转，必须先有资本垫底：盖厂房、买原料、付工人工资都得先花钱，这些钱就是资本。斯密把资本分为**固定资本**（厂房机器这类能用很多年的）和**流动资本**（原料、货币这类一次用完的）。他又把劳动分为**生产性劳动**（产出能进入市场交换的东西，比如织布，直接增加国民财富）和**非生产性劳动**（产出不进入市场，比如仆役、士兵、官吏的服务，要靠前者养）。所以一国要富，就要节俭储蓄、把储蓄变成资本、投到生产性劳动上去。资本流向哪里应当由回报率决定，自由流动比政府规定用途更有效率。

**富国是怎么长出来的**

这一块讲历史：文明社会「自然的次序」是先靠土地谋生，有了剩余再分工、蓄积资本，最后才发展商业。但欧洲的真实历史把这个次序倒了过来——罗马帝国崩溃后，封建领主制度压住农业，农民种得多也不归自己，没有激励；倒是工商业城市靠自治摆脱了领主控制，先富了起来；然后城市的需求和资本回流，反过来推动农村改良。斯密用这段历史说明：制度好不好，直接决定财富能不能长出来。

**错的政策为什么错**

这是全书火药味最重的地方。**重商主义**（把金银存量当国家财富、追求贸易顺差、用高关税和殖民垄断限制进口的政策体系）觉得出口多于进口就是在赚钱，于是到处设限制。斯密逐条拆穿：金银不是财富本身，只是交换媒介；限制进口抬高了国内物价，保护的是生产者的利益，损害的是消费者的利益；殖民垄断更是为少数商人牺牲整个国家。**重农主义**（认为只有土地产物才是财富、只有农业才真正创造财富的体系）则相反，斯密同样不买账：土地、劳动、资本三者都创造财富，正确做法是让三者各得其所，让市场自由竞争——这就是**看不见的手**（每个人只顾自己的利益，却像被一只无形的手牵引着，无意中也促进了社会利益）的含义。

**政府该干什么、钱从哪来**

斯密不是无政府主义者，他明确给出政府三项职责：国防（保卫国家安全）、司法（保护人民不受欺压）、公共工程（道路、桥梁、学校这类私人不愿做但对大家有益的设施）。这些是看不见的手管不到的地方，必须政府出手。财政上，他主张税收按收入比例征收、不随意加税；对**公债**（国家举债筹钱、让后代偿还当代开支）提出警告：债台高筑会侵蚀真实财富。

## 第三层：记忆挂钩

**这本书在跟谁吵架**：主线是跟**重商主义**吵架——那是当时英法荷等国奉行的主流政策，把金银当财富、追求贸易顺差、到处设限制。斯密「生产怎么变快」「错的政策为什么错」这两块，本质上都是在回应这场争论：先论证财富来自分工与生产而不是金银，再逐条拆穿重商主义的政策。副线是跟**重农主义**吵架——重农主义者认为只有农业创造财富，斯密说不对，土地、劳动、资本都创造财富。理解了这两场架，你就知道这本书的「位置」：它站在自由贸易和自由竞争这一边。

**前因后果**：1776 年出版，正当工业革命前夜，英国正从手工制造业向大工业过渡，行会特权、进口限制、殖民垄断这些旧制度卡着产业发展。斯密本人是苏格兰人，苏格兰当时被排除在英格兰的殖民贸易体系之外，这让他对重商主义的限制有切肤之痛。他之前写的《道德情操论》讲「利他与同情」，这本《国富论》讲「利己与分工」——两本书在斯密看来是一体的，合起来才是一个完整的人性论。

**核心概念及关系**（因果链）：

- 人天生有**交换的倾向** → 促成**分工** → **市场范围**决定分工能细到多深 → 分工提高生产率 → 国民财富增长。这构成「斯密增长模型」的正反馈：市场扩大 → 分工细化 → 收入提高 → 需求扩张 → 市场再扩大。
- 商品的价格 = 工资 + 利润 + 地租（三种收入）；自然价格是这三者「自然率」之和，是引力中心；市场价格围着它波动。
- 增长要靠资本垫底：储蓄 → 资本 → 投到生产性劳动上 → 财富增加；资本分固定资本与流动资本。
- 劳动价值论：劳动是价值的普遍尺度。
- 政策层面：重商主义/重农主义搞错方向 → 看不见的手被打断 → 只有自由贸易和有限政府能让市场自己转起来。

**与其他人/书的对话**：

- 李嘉图《政治经济学及赋税原理》：接着斯密发展劳动价值论，把分配问题推到前台。
- 马克思《资本论》：批判地吸收斯密的劳动价值论，但认为资本主义必然产生危机。
- 凯恩斯《就业、利息和货币通论》：反过来主张政府干预，针对「市场自动出清」失效。
- 哈耶克《通往奴役之路》：把斯密的「自发秩序」发展成反计划经济的旗帜。
- 科斯用「交易成本」补充斯密「分工由市场范围决定」的粗糙处。
- 在中国：严复 1902 年译《原富》，改革开放后「斯密」成为市场化改革的重要参照。

**论述题答题骨架**（考研用）：

- 立场示例——评价「看不见的手」：先给定义（私利 → 无意中促进公益），指出它在《国富论》里只出现一次、指向自然法则而非万能的「市场规律」，再分析适用边界（斯密明确要求政府守国防、司法、公共工程），最后联系现代经济学（市场失灵、外部性）做辩证评价。
- 论证组织：概念定义 → 书中论证 → 适用范围/局限 → 你的评价。这个骨架对「重商主义批判」「政府职能」「劳动价值论与马克思的比较」都适用。

## 如果考试遇到这本书相关的题，这几个点必须踩到

1. **定义要准**：把「看不见的手」定义为「私利驱动下无意中促进社会利益」的机制，并且要知道它在《国富论》中只出现一次，不是「市场万能」。
2. **分工三条机制**：熟能生巧、省转换时间、催生机器；且受市场范围限制——这是斯密增长模型的核心。
3. **价格理论**：三种收入（工资、利润、地租）构成价格；自然价格是引力中心，市场价格围绕它波动；劳动价值论是价值的普遍尺度。
4. **资本观**：固定/流动资本；生产性/非生产性劳动；储蓄 → 资本 → 生产性劳动 → 财富。
5. **两场批判**：重商主义（金银≠财富，限制贸易损人不利己）；重农主义（不只土地创造财富）——结论是自由贸易、自由竞争。
6. **政府三项职责**：国防、司法、公共工程——斯密不是「小政府/无政府」，这是常见误读，要澄清。
7. **历史论证**：先农后商的自然次序被欧洲历史倒置（城市先富、再反哺农村）——制度决定财富能否生长。
8. **联系与比较**：能说出与李嘉图、马克思、凯恩斯、哈耶克的关系；能答「斯密问题」——《道德情操论》与《国富论》不矛盾，利他与利己是一体的。
