## 二、四大板块复习大纲

### 板块 A · 理论地基：《机器学习》（周志华，2016）

主线口令：**定问题 → 立标尺 → 学样 → 寻序 → 进阶**。

必背要点：
1. 学习 = 从训练集归纳规则、靠测试集检验**泛化**；评估必须用没见过的数据（考卷不能出自练习册），头号敌人是过拟合（背答案），防法：交叉验证、剪枝、正则化、集成。
2. 五个主流模型一句话定位：决策树 = 连环是/否问答（信息熵选问题）；神经网络 = 层层加工（BP 顺差距回调）；SVM = 最大间隔 + 核函数升维；贝叶斯 = 概率投票（朴素 = 假设特征独立）；集成 = 三个臭皮匠（Boosting 串行补洞 / Bagging 并行投票）。
3. 无监督两大件：聚类（k-means 归堆）、降维（PCA 去繁存要）。
4. 泛化误差 = 偏差 + 方差 + 噪声（偏差是学力不够，方差是对扰动敏感，此消彼长）。
5. 没有免费午餐定理：脱离具体问题谈算法优劣没有意义。

### 板块 B · 技术主干：从 Transformer 到会提问

**B1《Attention Is All You Need》（Vaswani 等，2017）**——主线：提 → 搭 → 比 → 练 → 验。
1. 缩放点积注意力 softmax(QKᵀ/√d_k)V；除以 √d_k = 防点积过大、softmax 饱和、梯度消失。
2. 三把尺子：每层计算复杂度、最少串行操作数、最大路径长度——自注意力串行 1 步、路径 1 步（圆桌会议），代价是 O(n²)。
3. 位置编码必要（注意力对顺序失明）；掩码保自回归（不能偷看答案）；多头 = 多子空间多视角。
4. 误读辨析：注意力/自注意力都不是本文首创；标题是修辞（前馈、残差、归一化都不是注意力）；BERT/GPT 是后续工作。

**B2《自然语言处理原理与实战》（陈敬雷，2023）**——主线：切 → 表 → 判 → 系。
1. 中文分词两条路线：规则（最大匹配）vs 统计（HMM 字标注 B/M/E/S）。
2. 表示演进是全书主线：词袋 → TF-IDF（TF×IDF 挑关键词）→ Word2Vec 词向量（语义可计算）。
3. CRF 看上下文做序列标注；倒排索引（词→文档表）是搜索引擎快的根本。
4. 分类/聚类/摘要（抽取式挑原句 vs 生成式重写）；技术栈止于 BERT，无大模型专章。

**B3《ChatGPT 高效提问》（李世明等，2023/24）**——主线：识 → 搭 → 练 → 用。
1. 基础四要素：指令（唯一必填）、语境、输入数据、输出指标。
2. 高级五要素：能力与角色、洞察力、指令、个性、尝试。
3. 基本原则 7 条至少列 4 条：简明清晰、具体化、聚焦、有上下文、确定生成目标、语法规范、验证准确性。
4. 少样本示例（模仿格式）与思维链（推理任务）各管一摊；幻觉 → 必须人工验证。

**板块 B 串联线**：Attention 给原理底座 → NLP 实战给任务与工程 → ChatGPT 给使用方法论；表示一路升级：词袋 → TF-IDF → 词向量 → 注意力表示 → 预训练大模型 → Prompt。

### 板块 C · AI 全景：《人工智能：一种现代的方法》（Russell & Norvig，2020/2022）

主线口令：**定 → 搜 → 推 → 测 → 学 → 用**（收在价值对齐）。
1. 理性 Agent = 给定感知序列 + 内建知识，选期望性能最大的行动（理性 ≠ 全知、≠ 结果最优）；PEAS 四件套。
2. A* 最优性条件：h(n) 不高估，f = g + h。
3. 贝叶斯网络：联合概率拆成条件概率乘积；先验/似然/后验分清。
4. MDP 四要素（状态、动作、转移、奖励）+ 值迭代/策略迭代；监督（有标注）vs 强化（只有奖励）。
5. 第 4 版新增深度学习、概率编程、多智能体三章 = "紧跟时代"；全书收束在价值对齐。

### 板块 D · 智能与人和社会

**D1《面向共融机器人的自然交互》（徐华，约 2022—2023）**——主线：听清 → 听懂 → 记住 → 稳住 → 落地。
1. 共融机器人 / 人机共融三层（物理、信息、认知），自然交互是前提。
2. SLU 三层结构：领域—意图—槽值（一句话 = 一张任务单）。
3. 联合模型优于"先意图后槽值"两步走；多模态与情感补纯文本短板。
4. 开放环境：噪声、未知意图 → 鲁棒、拒识、增量学习；大模型正在改写 SLU 路线。

**D2《智能时代》（吴军，2016）**——主线：数 → 智 → 思 → 商 → 治。
1. 大数据三特征：体量大、多维度、完备性——完备数据让"笨方法"重新有效。
2. 机械思维（因果、确定性）vs 数据思维（强相关替代因果）；"变智能问题为数据问题"。
3. 现有产业 + 机器智能 = 新产业（改造而非取代）。
4. 社会账单：无隐私社会、就业冲击；"2% 的人"判断及其争议。

**D3《网络舆情治理：理论与实务》（陈华明主编，2023）**——主线：辨 → 演 → 立 → 防 → 断 → 应。
1. 舆情 ≠ 舆论：舆情还含潜在情绪与态度，治理对象更宽。
2. 构成要素五件套：主体、客体、载体、本体、环境。
3. 生命周期：潜伏—生成—扩散—高潮—回落—长尾，分阶段施策。
4. 次生舆情：处置不当（回应失当、删帖封堵）引发"针对处置本身"的新舆情；对策 = 信息公开 + 线下解决。
5. 实务链条：监测 → 预警 → 研判 → 引导应对，落点在线下联动。

**D4《AI 未来进行式》（李开复、陈楸帆，2022）**——主线：演 → 拆 → 收。
1. 双轨结构："科学小说" = 2042 科幻故事（A 面）+ 技术解读（B 面）；阿玛拉定律（高估短期、低估长期）。
2. 七项技术对号入座：深度学习(1)、计算机视觉(2)、NLP(3)、数字医疗与机器人(4)、元宇宙/XR(5)、自动驾驶(6)、量子计算与自主武器(7)。
3. 人的议题三问：工作（哪些难被取代：创造力、共情、手艺；UBI）、幸福（情绪数据归谁）、丰饶（后稀缺经济）。
4. 核心立场：AI 是工具，威胁来自人的使用与制度。

## 三、四条跨书主线（大题就考这个）

1. **技术演进线**：机器学习（统计地基）→ Attention（范式转移）→ NLP 实战（工程任务）→ ChatGPT 提问（使用方法论）→ AIMA 第4版（全景收编大模型）。一句话：从"人设计特征与规则"到"数据与表示自己长出来"，人的角色从"实现者"变成"提问者"。
2. **方法论线**：数据思维（吴军）↔ 机械思维；呼应机器学习"数据+模型+评估"三体与 Attention"用数据换智能"——三本书从三个高度说同一件事：完备数据 + 简单方法 > 精巧理论 + 稀缺数据。
3. **人机与社会线**：共融机器人（怎么协同）→ 智能时代（社会账单）→ 网络舆情（治理实务）→ AI 未来进行式（伦理想象）→ AIMA 价值对齐（技术伦理收尾）。核心张力：能力增长与责任边界同步。
4. **竞争力线**：ChatGPT"会问" + AI 未来进行式"创造力/共情/手艺" + 智能时代"2%"——三者互证：AI 时代的护城河在提问、创造与共情，不在记忆与重复。

## 四、高频论述题演练（4 道，附骨架）

1. **从统计机器学习到大语言模型，技术如何一步步演进？**（组合 1/2/3/4）
   骨架：统计学习立地基（评估与泛化意识）→ 表示革命（词向量 → 注意力取代循环）→ 预训练范式（BERT/GPT 两支）→ 规模与提示工程 → 人的角色转变为"会问的人"。
2. **"数据思维"能否取代"机械思维"？边界在哪里？**（组合 7/1/5）
   骨架：数据思维的胜利（翻译、推荐、AlphaGo）→ 边界一：因果不可全弃（安全关键、科学发现）→ 边界二：数据完备性是前提 → 结论：互补而非取代。
3. **AI 时代个人的核心竞争力与社会的应对**（组合 4/9/7）
   骨架：会问是杠杆（prompt 四要素）→ 护城河三样（创造力、共情、手艺）→ 制度应对（UBI、隐私归属）→ 对"2%"表态：警惕淘汰论，主张转型论。
4. **智能系统的"治理"：从舆情到价值对齐**（组合 8/5/6/7）
   骨架：治理对象多元（舆论生态 / 算法 / 机器人）→ 共同原则（信息公开、多元协同、目标对齐）→ 边界（隐私、表达权、安全）→ 结论：技术上限由制度下限兜底。
